# OCR 比較結果

釣果トースト(画面左下の通知)を読むエンジンの比較。`pocofarm bench-ocr` で Windows OCR と PP-OCR の行を再現できる(Tesseract は当時の一回限りの計測で、再現手段は残していない)。


| エンジン | 通知種別の分類 | 魚名・経験値・所持数を全取得 | 平均時間 |
|---|---|---|---|
| Windows OCR (winocr, ja) | 60/60 | 56/60 | 約 46 ms |
| RapidOCR (PP-OCR, onnxruntime) | **60/60** | **60/60** | 約 780 ms |

サンプルは `tests/fixtures/ocr/` の固定 60 枚(原寸画面から切り出したトースト領域)。`pocofarm bench-ocr tests/fixtures/ocr` で再現できる。
縮小保存した証拠画像(幅 1100px)は文字が潰れて Windows OCR の正答率が大きく下がるため、比較には使わない。
Windows OCR を 1.5〜2 倍に拡大・グレースケール化しても結果はほぼ変わらず(56〜58/60)、所要時間だけ増えるので前処理は入れていない。

補助的に試した前処理(金色文字の HSV 抽出+Tesseract、PSM 11)は 43/51・48/51 で、素の PSM 6 より悪かった。

## 採用方針

1. **常用: Windows OCR**。50 ms なので 0.12 秒間隔でトースト領域を読み続けられ、引いた直後 40〜150 ms で結果を取れる。
2. **再確認: RapidOCR**。Windows OCR で「文字はあるのに種別を判定できない」「釣果だが魚名/経験値/所持数が欠けている」場合だけ、同じ画像を RapidOCR に渡す。誤読が最も少ないため確定値に使う。
3. **救済: RapidOCR による再読取り**。引いた後に結果が読めなかった場合、クリック以降に切り出したトースト領域画像(メモリ上のリング。最大 6 枚、確認クリックは 1 枚)を RapidOCR で読み直す。それでも読めなければ `unknown` として画面証拠付きで記録する。
4. Tesseract 5(jpn, psm6)も試したが、精度が Windows OCR 以下(50/60)で外部プロセス起動のため遅く(約 490 ms)、採用していない。比較用の実装は残していない。

## 付随通知

釣果通知がレベルアップ(`レベル20になった!`)や実績(`実績「畑マスター」を達成!`)に押し出されることがある。
これらは種別 `levelup` / `achieve` として扱い、結果待ちを最大 6 秒延長する。釣果通知が最後まで出なければ、経験値が入った事実から `caught`(魚種不明)として記録する。
